# ClipSlim v2.0 — Spec B: Workflows & Automation

## Overview

Add system-wide shortcuts, in-panel keyboard navigation, Share extension, CLI tool, and batch rename templates. These features make ClipSlim accessible from anywhere on macOS — not just from the menubar.

Depends on Spec A (Share/CLI need to handle video, GIF, SVG).

## Features

### 1. Global Shortcuts (System-Wide)

**Goal:** Summon ClipSlim actions from any app with configurable hotkeys.

**Default hotkeys:**

| Default | Action |
|---------|--------|
| `Opt+Shift+D` | Toggle Drop Zone window |
| `Opt+Shift+R` | Quick Resize popover |
| `Opt+Shift+C` | Quick Crop popover |
| `Opt+Shift+V` | Paste & Optimize (optimize current clipboard, replace) |
| `Opt+Shift+G` | Convert clipboard video to GIF |
| `Opt+1` | Copy last optimized (existing) |
| `Opt+2` | Copy last original (existing) |

**Implementation:**
- Extend existing `HotkeyCoordinator` (already uses Carbon HIToolbox)
- New `ShortcutAction` enum with all 7 actions
- `ShortcutBinding` struct: modifiers (UInt), keyCode (UInt32) — stored in UserDefaults as JSON
- Conflict detection: warn if user shortcut clashes with existing macOS system shortcuts
- Settings UI: new "Shortcuts" card in General tab — lists all hotkeys with "Record Shortcut" buttons
- Recording: `KeyRecorderView` using `NSEvent.addLocalMonitorForEvents(matching: .keyDown)` to capture combos

**Quick Resize Panel:**
- New `ClipSlim/Views/QuickResizePanel.swift` — `NSPanel` (non-activating, floating)
- Content: width/height inputs with linked aspect ratio toggle, preset buttons (512x512, 1024x1024, 1920x1080), "Apply" button
- Flow: read clipboard → resize via `ImageOptimizer` → write back → show overlay
- Dimension clamping: 16-8192
- Uses `VibeCheckTheme` — dark background, neon cyan accents, monospaced dimension text
- Dismiss on Esc, click outside, or after apply

**Quick Crop Panel:**
- New `ClipSlim/Views/QuickCropPanel.swift` — same panel pattern
- Content: shape picker (square/circle), size input, "Apply" button
- Same flow: read clipboard → crop → write back → show overlay

**Files:**
- Modify: `ClipSlim/Coordinators/HotkeyCoordinator.swift`
- Create: `ClipSlim/Models/ShortcutAction.swift`
- Create: `ClipSlim/Views/QuickResizePanel.swift`
- Create: `ClipSlim/Views/QuickCropPanel.swift`
- Create: `ClipSlim/Views/Components/KeyRecorderView.swift`
- Modify: `ClipSlim/Views/Settings/GeneralTab.swift` (shortcuts card)

### 3. Share Extension

**Goal:** Optimize files from any app's Share menu.

**Implementation:**
- New target `ClipSlimShare/`
- `ShareViewController.swift` — `NSViewController` with SwiftUI hosting
- Extension UI: filename display, preset picker (segmented: Web/High/Compressed/Lossless), output choice (Save File / Copy to Clipboard), "Optimize" button
- Supported UTTypes: `public.image`, `public.movie`, `com.compuserve.gif`, `public.svg-image`, `com.adobe.pdf`
- Processing: sequential (extension memory limits), progress bar for multi-file
- Output: writes `_optimized` alongside original, or copies to clipboard (user choice)
- Skip files >100MB with warning

**Shared code:**
- Both Share Extension and Finder Quick Action need optimizers
- Shared files via dual target membership: `ImageOptimizer`, `PDFOptimizer`, `VideoOptimizer`, `GIFOptimizer`, `SVGOptimizer`, all model files
- Group shared files under `ClipSlimShared/` for clarity

**Info.plist:**
```xml
<key>NSExtensionActivationRule</key>
<string>SUBQUERY(extensionItems, $item, SUBQUERY($item.attachments, $att,
  ANY $att.registeredTypeIdentifiers UTI-CONFORMS-TO "public.image" OR
  ANY $att.registeredTypeIdentifiers UTI-CONFORMS-TO "public.movie" OR
  ANY $att.registeredTypeIdentifiers UTI-CONFORMS-TO "com.compuserve.gif" OR
  ANY $att.registeredTypeIdentifiers UTI-CONFORMS-TO "public.svg-image" OR
  ANY $att.registeredTypeIdentifiers UTI-CONFORMS-TO "com.adobe.pdf"
).@count > 0).@count > 0</string>
```

**UI consistency:** Dark background matching VibeCheckTheme, neon cyan accent on "Optimize" button, orange preset selection, monospaced file size text.

**Files:**
- Create: `ClipSlimShare/ShareViewController.swift`
- Create: `ClipSlimShare/Info.plist`
- Modify: Xcode project (new Share Extension target)

### 4. CLI Tool

**Goal:** Command-line interface for developers to optimize files, batch process directories, and watch folders.

**Binary:** `clipslim` (lowercase) — bundled at `ClipSlim.app/Contents/MacOS/clipslim`, symlinked to `/usr/local/bin/clipslim` via Settings "Install CLI" button.

**Interface:**

```
USAGE: clipslim <subcommand> [options]

SUBCOMMANDS:
  optimize    Optimize a single file
  batch       Optimize all files in a directory
  watch       Watch a directory and optimize new files
  info        Show file information

GLOBAL OPTIONS:
  --json      Output as JSON (for scripting)
  --quiet     Suppress non-error output
  --version   Show version
  --help      Show help
```

**Optimize subcommand:**
```
clipslim optimize <file> [options]
  --preset <web|high|compressed|lossless|custom>  (default: web)
  --format <jpeg|png|webp|avif>
  --quality <0.0-1.0>
  --max-dimension <pixels>
  --strip-metadata
  --output <path>       (default: alongside original with _optimized suffix)
  --dry-run             (show what would happen without writing)
```

**Batch subcommand:**
```
clipslim batch <directory> [options]
  (all optimize options plus:)
  --recursive           (traverse subdirectories)
  --rename <template>   (rename template, e.g., "{name}_{date}.{ext}")
```

**Watch subcommand:**
```
clipslim watch <directory> [options]
  (all optimize options)
  (runs until Ctrl+C)
```

**Info subcommand:**
```
clipslim info <file>
  (prints: format, dimensions, file size, has-alpha, duration/codec for video)
```

**Implementation:**
- New target `clipslim` — macOS Command Line Tool
- Dependency: `swift-argument-parser` (Apple-maintained)
- Entry: `@main struct ClipSlimCLI: AsyncParsableCommand` with subcommands
- Each subcommand: parse args → build config → call optimizer → format output
- `--json` outputs one JSON object per file: `{"input": "path", "inputSize": N, "output": "path", "outputSize": N, "savings": "42%", "format": "avif"}`
- Watch mode: `DispatchSource.makeFileSystemObjectSource` + `RunLoop.current.run()`, 300ms debounce
- SIGINT handler for clean exit
- Install symlink: Settings button triggers `ln -sf` with admin prompt

**Files:**
- Create: `clipslim/ClipSlimCLI.swift`
- Create: `clipslim/Commands/OptimizeCommand.swift`
- Create: `clipslim/Commands/BatchCommand.swift`
- Create: `clipslim/Commands/WatchCommand.swift`
- Create: `clipslim/Commands/InfoCommand.swift`
- Modify: `ClipSlim/Views/Settings/GeneralTab.swift` (Install CLI button)
- Modify: Xcode project (new CLI target + swift-argument-parser dependency)

### 5. Batch Rename Templates

**Goal:** Template-based renaming for folder watcher and drop zone output files.

**Template tokens:**

| Token | Output | Example |
|-------|--------|---------|
| `{name}` | Original filename (no extension) | `hero` |
| `{ext}` | Output extension | `webp` |
| `{date}` | YYYY-MM-DD | `2026-04-06` |
| `{time}` | HH-mm-ss | `14-30-22` |
| `{n}` | Sequential number (zero-padded) | `001` |
| `{width}` | Output width | `1920` |
| `{height}` | Output height | `1080` |
| `{format}` | Format name (lowercase) | `avif` |
| `{preset}` | Preset display name | `Web quality` |
| `{savings}` | Savings percentage (integer) | `42` |

**Default template:** `{name}_optimized` (matches current behavior, extension auto-appended)

**Implementation:**
- New `ClipSlim/Services/BatchRenamer.swift` — pure static function: `static func rename(template: String, context: RenameContext) -> String`
- `RenameContext` struct with all token values
- Template parsing: scan for `{`, find `}`, look up token in dictionary. Unknown tokens left as literal (no crash on typos).
- Applied to: folder watcher output and drop zone output. NOT clipboard (no file output by default).

**Settings UI:**
- New "Output Naming" card in Folders tab
- Template text field with live preview showing example output
- Preset buttons: "Default" (`{name}_optimized`), "Dated" (`{name}_{date}_{time}`), "Full" (`{name}_{date}_{n}_{width}x{height}`)
- Uses `VibeCheckTheme` — monospaced preview text, hint text explaining tokens

**Files:**
- Create: `ClipSlim/Services/BatchRenamer.swift`
- Create: `ClipSlim/Models/RenameContext.swift`
- Modify: `ClipSlim/Views/Settings/FolderTab.swift` (Output Naming card)
- Modify: `ClipSlim/Models/AppSettings.swift` (renameTemplate)
- Modify: `ClipSlim/Coordinators/ProcessingCoordinator.swift` (apply rename in file output)

## UI Consistency Requirements

All new UI elements follow existing patterns:
- **Settings cards:** `VibeSettingsPage` > `VibeSettingsCard` > `VibeHintText`
- **Typography:** `VibeCheckTheme.Typography` — `.body` labels, `.caption` hints, `.monospacedBold` metrics/dimensions
- **Colors:** `.neonCyan` positive, `.neonOrange` accents, `.textPrimary/.textSecondary/.textTertiary` hierarchy
- **Spacing:** `VibeCheckTheme.Spacing.xs/sm/md/lg/xl`
- **Panels:** `NSPanel` non-activating, floating, dark background (#111116 @ 82% + ultraThinMaterial), orange border gradient, same shadow as overlay
- **Segmented pickers:** Orange selection color, matching preset/format pickers
- **Buttons:** Same `actionButton` style as overlay for Quick Resize/Crop

## Performance Considerations

| Feature | Risk | Mitigation |
|---------|------|------------|
| Global shortcuts | Too many Carbon hotkeys | Unique IDs, deregister on quit, conflict detection |
| Quick panels | Large clipboard image processing | Task.detached, spinner during processing |
| Share extension | 120MB memory limit | Sequential processing, skip >100MB files |
| CLI batch | Thousands of files | Sequential with progress, JSONL streaming, SIGINT handler |
| CLI watch | Missed events on burst | 300ms debounce, sequential queue |
| Batch rename | Negligible | Pure string operation |

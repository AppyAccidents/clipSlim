## Week 2 Post-Approval (Baseline Completion)

### Day 8-14
- [ ] Continue daily monitoring (15 min/day)
- [ ] Record Day 14 baseline metrics
- [ ] Evaluate if A/B testing is feasible (need 1,000+ impressions minimum)
- [ ] If less than 1,000 impressions: extend baseline to Day 21

### Day 14 Decision Point
- [ ] CVR below 20%: start Screenshot 1 test immediately
- [ ] CVR 20-35%: proceed with planned test schedule
- [ ] CVR above 35%: focus on driving more impressions (keyword optimization)
